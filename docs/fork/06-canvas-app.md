# 画布应用

## 归属

画布留在本仓库，以后作为 `web/src/features/canvas`，路由预留 `/canvas`。不单独立项，不搬其它仓库的页面实现。本轮不创建该目录，也不写页面。

## v1

- 单用户。
- 节点类型只有 `text`、`image`。
- 连线。
- 平移缩放。
- 撤销重做。
- 生图走本仓库现有网关模型。
- 草稿只留本地。

## 不做

实时协作、Fabric 导演、Three/全景、吉祥物、分镜、版本历史、压测、分享、第二套积分、独立 Agent 面板。

## 职责边界

- 文档模型：保存节点、连线和草稿。
- 舞台：平移、缩放、摆放节点。
- 连线：连接节点。
- 生图：调用本仓库已有网关模型，把结果放进 `image` 节点。
